Buffer API (Agendamento Multicanal Unificado)

Publicação e agendamento para Instagram, Facebook, LinkedIn, X, TikTok e Pinterest em um só lugar.

Altamente Recomendado
Campos necessários no Social360:
  • Access Token do Buffer
  • IDs dos Perfis (separados por vírgula)
  1. Conectar suas redes no Buffer: Acesse buffer.com e adicione os canais sociais da sua empresa/cliente normalmente no painel.
  2. Criar o App de Desenvolvedor: Acesse o portal de desenvolvedores do Buffer: buffer.com/developers/apps.
    Clique em "Create an App", nomeie como Social360 Studio e preencha as URLs com seu domínio (ex: https://social360.anauedesign.com.br).
  3. Copiar o Access Token: Na tela do app criado, você verá o seu Access Token permanente. Copie e cole no campo Access Token do Buffer no Social360.
  4. Localizar os IDs dos Perfis (Profile IDs): No painel normal do Buffer, clique no ícone da rede social desejada na barra lateral esquerda. Observe a URL do seu navegador: https://publish.buffer.com/profile/64b8a123456789abcdef/tab/queue O código após /profile/ (ex: 64b8a123456789abcdef) é o Profile ID.
    Se tiver mais de um perfil, copie os códigos de cada um e separe por vírgula no formulário: 64b8a123456789abcdef, 64c9f987654321fedcba
💡
Dica de Ouro: Com o Buffer, você não precisa solicitar aprovações empresariais na Meta ou no LinkedIn. O Buffer gerencia todos os limites de postagem de forma transparente.

Telegram (Canal ou Grupo)

Disparo direto com notificações ricas e formatação HTML. Leva menos de 2 minutos para configurar.

Mais Simples & Rápido
Campos necessários no Social360:
  • Bot Token (do @BotFather)
  • Chat ID ou @username_canal
  1. Criar o Bot com o @BotFather: No Telegram, pesquise pelo bot oficial @BotFather (com o selo de verificado). Envie a mensagem: /newbot Siga as instruções, escolha um nome (ex: Social360 Notícias) e um username terminando em bot (ex: social360_noticias_bot).
  2. Copiar o HTTP API Token: O BotFather responderá com o Token de acesso: 7123456789:AAFlKj9823hjasd89123-kasd98123 Copie e cole no campo Bot Token no Social360.
  3. Adicionar o Bot como Administrador: Vá no canal ou grupo onde as notícias serão enviadas ➔ Gerenciar Canal ➔ Administradores ➔ Adicionar Administrador. Busque pelo username do seu bot e conceda permissão de Postar Mensagens.
  4. Definir o Chat ID: • Se o canal for Público: Use o @ do canal. Exemplo: @meucanal ou @anauedesign.
    • Se o canal for Privado ou Grupo: Adicione o bot @RawDataBot no canal por 1 minuto. Ele revelará o ID numérico (ex: -1001928374650). Copie o número completo com o sinal de menos.

Webhook (n8n, Make, Zapier, Metricool)

Ideal para automações avançadas via fluxos low-code (WhatsApp, disparos customizados, CRM).

Campos necessários no Social360:
  • URL do Webhook
  1. No n8n: Crie um novo workflow, adicione um nó inicial Webhook, configure o método como POST e copie a Production URL (ex: https://n8n.seu-dominio.com.br/webhook/social360).
  2. No Make (Integromat): Crie um cenário, adicione o módulo Custom Webhook, clique em Create a Webhook e copie o link gerado.
  3. Colar no Social360: Cole a URL no campo correspondente e clique no botão "Testar". O Social360 enviará um ping de handshake para validar a recepção.

LinkedIn Direct API (v2)

Publicação direta em Company Pages ou perfis pessoais, com suporte a Carrosséis PDF.

Campos necessários no Social360:
  • Access Token (OAuth 2.0)
  • Author URN (ex: urn:li:organization:12345678)
  1. Acessar o LinkedIn Developers: Acesse linkedin.com/developers/apps e clique em "Create App".
  2. Associar a Página da Empresa: Preencha o nome do app, associe a sua Company Page do LinkedIn e envie uma solicitação de verificação para a página.
  3. Adicionar Produtos: Na aba Products, solicite acesso aos produtos Share on LinkedIn e Sign In with LinkedIn using OpenID Connect.
  4. Gerar o Access Token: Na aba Auth ➔ OAuth 2.0 Tools, selecione o app, marque os escopos w_member_social (ou w_organization_social) e clique em Request Token. Copie o token de acesso.
  5. Obter o Author URN da Empresa: Abra sua Company Page no LinkedIn. Olhe a URL no navegador: https://www.linkedin.com/company/12345678/admin/ O número 12345678 é o ID da empresa. Seu Author URN será: urn:li:organization:12345678

Meta Graph API (Facebook & Instagram)

Publicação oficial no Feed do Facebook e perfil comercial do Instagram.

Campos necessários no Social360:
  • Page Access Token
  • Page ID
  • Instagram Account ID
  1. Pré-requisito: A sua Página do Facebook e sua Conta Profissional do Instagram precisam estar vinculadas no Meta Business Suite.
  2. Criar App no Meta for Developers: Acesse developers.facebook.com/apps ➔ Criar aplicativo ➔ Outro ➔ Empresa.
  3. Gerar o Token no Graph API Explorer: Acesse developers.facebook.com/tools/explorer/.
    Selecione a sua Página em User or Page e adicione as permissões: pages_show_list, pages_manage_posts, instagram_basic, instagram_content_publish.
  4. Obter o Page ID e Instagram Account ID: Faça uma requisição GET no Graph API Explorer para: me?fields=id,name,instagram_business_account O retorno trará o id da Página do Facebook e o instagram_business_account.id.
  5. Estender Token para Longa Duração: No Token Debugger, cole o token gerado e clique em "Estender Token de Acesso" para obter o token de 60 dias ou permanente.

X / Twitter API (v2)

Publicação de tweets isolados e threads completas encadeadas automaticamente.

Campos necessários no Social360:
  • Bearer Token ou User Access Token
  1. Acessar o X Developer Portal: Acesse developer.x.com/en/portal/dashboard e faça login.
  2. Criar o App: Em Projects & Apps, crie um novo aplicativo (ex: Social360 Studio).
  3. Configurar Permissão de Escrita: Em Settings ➔ User authentication settings, defina a permissão como Read and Write (obrigatório para postar).
  4. Copiar o Token: Na aba Keys and Tokens, gere o Bearer Token ou OAuth 2.0 User Token e cole no Social360.

Chaves de Inteligência Artificial (Opcional por Cliente)

Permite que cada cliente utilize sua própria cota ou modelo dedicado de IA na redação de copies.

  1. Google Gemini (Recomendado pela velocidade e contexto): Gere gratuitamente em: aistudio.google.com/app/apikey
  2. OpenAI (ChatGPT / GPT-4o): Gere em: platform.openai.com/api-keys
  3. Anthropic Claude (Melhor redação editorial humana): Gere em: console.anthropic.com/settings/keys
  4. Groq (Gerações instantâneas com Llama 3.3): Gere gratuitamente em: console.groq.com/keys
🔌

Validação em Tempo Real no Studio

Após preencher os dados de qualquer rede, clique no botão "Testar" correspondente no painel do cliente. O Social360 fará uma chamada oficial à API e confirmará se as credenciais estão 100% operacionais antes de qualquer publicação real.
